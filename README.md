# Task work

Started from a 1Works task. This repository was created from the 1Works starter so it
is never empty, which lets GitHub Codespaces open on it.

## How to use it

1. Open this repo in a Codespace (Code, then Codespaces, then Create).
2. Build your work here and commit as you go.
3. Run `git push` from the Codespace terminal. It is already signed in as you.
4. Submit this repo's link in the task's Deliverables tab on 1Works.

If the repo is private, give your reviewer access on GitHub first.

Replace this file with notes about your own work whenever you like.
